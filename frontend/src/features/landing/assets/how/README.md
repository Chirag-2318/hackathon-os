# How it works screenshots

Drop the product screenshots for the "How it works" section in this folder.

- File names: stage-01.webp to stage-08.webp (.avif, .png, .jpg, .jpeg also work; add a -dark twin for the dark theme).
- Size: 1568 x 1000 pixels, light theme, 2x pixel ratio, each under 120KB.
- Source: one seeded fictional room (event "Campus Build Sprint 2026", project "Club budget tracker", team of four with initial-letter avatars only). No real names, emails or repo names, and no browser chrome.
- Until an image exists, the section shows a placeholder that describes what to capture.
- Dark versions: add `stage-01-dark.webp` and so on next to the light files; the page shows them automatically in the dark theme.
